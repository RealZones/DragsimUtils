# Changelog

## 1.1.0

Ported to Minecraft 26.2 on Fabric Loader 0.19.5 and Fabric API 0.161.0.

- Follows the 26.2 move of screens and HUD state into Gui and Hud.
- Hotbar rarity outlines and action bar reading hook into Hud.
- Chat colour lookups use TextColor, team sidebars use the new TeamColor.
- Concrete and entity type lookups use the new block colour collections and EntityTypes.

## 1.0.0

Initial Dragsim Utils release for Minecraft 26.1.2 on Fabric.

- Dragon, zealot, slayer and personal drop tracking.
- Dungeon map, key alerts, puzzle/terminal guidance and personal bests.
- Mining sessions, powder rates, drill fuel information and forge/recipe tools.
- Storage previews, item inspection and inventory protection options.
- Player profile browsing for inventory, pets, progression and public rankings.
- Missing collection suggestions exclude the unreleased Auto Recombobulator, Scarf's Thesis and Blaze pet.
- Customizable HUDs, themes, favorites, settings search and module shortcuts.
- Optional Discord Rich Presence with controls for shared activity details.
- One-time import of compatible Endsight settings and tracker history.
- Manual updates with readable sources and artifact verification instructions.

Networth is temporarily disabled. Remote item pricing is not included in 1.0.0.
